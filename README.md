# ⏳ Time Capsule 3.0 ⏳

Welcome to **Time Capsule 3.0** – the modern, next-generation digital memory keeper and future vault platform! Built with **Next.js (App Router)**, **React**, **TypeScript**, **MongoDB**, and **Tailwind CSS**.

---

## 🌟 What's New in Version 3.0

- 🚀 **Next.js Full-Stack Architecture**: Instant page transitions, serverless API endpoints, and clean React components.
- ⏳ **Live Countdown Timers**: Real-time ticker (`Xd Xh Xm Xs`) showing exactly when sealed time capsules will unlock.
- 🎉 **Unlock Celebrations**: Automatic unlock detection with confetti animations when capsules reach their milestone date.
- 🎨 **Dynamic Theme Engine**: Change font sizing, primary color palettes (Purple, Gold, Crimson, Green, Blue), and background modes (Light, Dim, Lights Out) on the fly.
- 🔒 **Sealed Vault Security**: Granular privacy controls (`Private`, `Friends`, `Public`, `Specific Friend`).
- ⚡ **Zero-Config Demo Mode**: Works immediately out of the box with offline demo fallback if MongoDB is not yet configured.
- ☁️ **100% Free Cloud Hosting**: Ready for one-click deployment on **Vercel** with **MongoDB Atlas Free M0**.

---

## 📸 Core Pages & Features

1. **Authentication**: Glassmorphism Login (`/login`) & Signup (`/signup`) with instant demo login.
2. **Timeline Dashboard (`/`)**: 3-column feed with Stories, instant memory posting, dynamic likes/comments, and capsule network.
3. **Schedule Capsule (`/schedule`)**: Seal memories for 1 year in the future or on a custom date with photos.
4. **Time Capsule Vault (`/view-scheduled-messages`)**: Manage active countdowns and unlock sealed memories.
5. **Memory Posts (`/view-posts`)**: Dedicated view of all user memories and timeline entries.

## 📦 Getting Started Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env.local`:
```bash
cp .env.example .env.local
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
